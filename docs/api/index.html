CommerCity API

La referencia interactiva no pudo cargarse (sin JavaScript, sin red hacia el CDN o bloqueo por Content-Security-Policy del backend).

  • JSON OpenAPI: openapi.json (importable en Postman/Insomnia).
  • Local: sirve esta carpeta con cualquier estatico (npx serve docs/api) y recarga.
  • Regenerar: npm run docs:api desde backend/.
